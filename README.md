# Jonas Oliveira - Portfólio Pessoal

Este projeto é um portfólio pessoal desenvolvido como parte das atividades práticas do curso de **Desenvolvimento Web Full Stack** da **Oxetech**, ministrado pela instrutora **Lavínia Emelly**.

## 🚀 Sobre o Projeto

O objetivo principal deste projeto é aplicar os conceitos fundamentais de desenvolvimento web, focando em estrutura semântica com HTML5 e estilização moderna com CSS3.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Utilizado para a criação da estrutura semântica da página, garantindo acessibilidade e SEO.
- **CSS3**: Utilizado para o design visual, incluindo o uso de Flexbox para layout e Media Queries para responsividade.

## 📋 Funcionalidades

- **Cabeçalho Responsivo**: Menu de navegação que se adapta a diferentes tamanhos de tela.
- **Seção Sobre**: Uma breve introdução sobre o desenvolvedor.
- **Galeria de Projetos**: Exibição de projetos realizados, utilizando uma estrutura de cartões (articles).
- **Rodapé**: Informações de direitos autorais e ano de criação.

## 💻 Como Visualizar

Para ver o projeto em funcionamento:
1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
