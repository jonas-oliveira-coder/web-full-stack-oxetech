Vocês devem construir uma "Landing Page de um Dashboard". Deve ser totalmente Mobile First. No Desktop (acima de 1024px), use CSS Grid para criar uma estrutura clássica: Sidebar na esquerda, Header no topo, e Conteúdo Principal (cards). Use Media Queries para esconder a sidebar no mobile e mostrá-la no desktop. Os cards internos devem usar Flexbox. Subam no GitHub pages e enviem o link por e-mail. Bom código!
